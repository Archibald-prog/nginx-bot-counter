# Nginx Bot-Scanner Counter

Скрипт для сканирования файла логов Nginx *access.log* на предмет наличия запросов от ботов-сканеров и составления итогового черного списка  IP-адресов ботов. 

## 🛠️ Функционал

`log_parser.py` — анализирует файл логов *access.log*, выявляет записи с кодом ответа 404 (*Not Found*), подсчитывает число IP-адресов, запросы от которых генерируют такой ответ. Составляет черный список IP-адресов наиболее агрессивных ботов и сохраняет список в каталоге скрипта. 

## 🚀 Запуск и тестирование

Скрипт автономно работает с абсолютными путями операционной системы и не требует передачи аргументов командной строки.

* **На боевом сервере (Production):** скрипт считывает живой лог по стандартному системному пути `/var/log/nginx/access.log`.
* **Для локального теста:** чтобы проверить скрипт на домашнем ПК без установленного веб-сервера, перед запуском отредактируйте переменную `LOG_FILE` в коде скрипта, указав путь к вашей локальной копии лога.

```bash
# 1. Клонировать утилиту
git clone https://github.com/Archibald-prog/nginx-bot-counter.git
cd nginx-bot-counter

# 2. Запуск анализатора (требуются права на чтение системных логов)
sudo python3 log_parser.py
```

## ⚙️ Системные требования
* Операционная система: Ubuntu / Debian / CentOS
* Интерпретатор: Python v3.8+
* Права доступа: root / sudo-привилегии
